# KANT COURT 시네마틱 에셋 출처

| 프로젝트 파일 | 제공 원본 |
|---|---|
| court-door-closed.webp | 사용자가 첨부한 닫힌 법정 문 (12_29_56-1.png) |
| court-door-open.webp | 사용자가 첨부한 열린 법정 문 (12_29_59-2.png) |
| judge-gavel-raised.webp | 사용자가 첨부한 의사봉 준비 장면 (12_30_03-3.png) |
| judge-gavel-strike.webp | 사용자가 첨부한 의사봉 타격 장면 (12_30_06-4.png) |

네 장은 프로젝트에 사용하도록 제공된 일러스트입니다. WebP 변환에서 원본 해상도와 포함된 색상 프로파일을 보존했습니다. 타격 장면은 제공 이미지에 포함된 선고 문구를 사용합니다.

문 열림, 환경음, 의사봉, 문서, UI 효과음은 court-audio.js에서 Web Audio 오실레이터와 필터를 적용한 잡음으로 합성합니다. 이 프로젝트에는 외부 오디오 녹음이나 별도 샘플 라이선스가 포함되지 않습니다.
