# 원문 데이터

| 폴더 | 내용 | 수집 방법 |
| --- | --- | --- |
| `statutes/` | 법령 본문 (조문 단위 텍스트) | `uv run python scripts/fetch_law.py` (국가법령정보센터 Open API, `LAW_OC` 필요) 또는 law.go.kr 본문을 복사해 저장 |
| `cases/` | 판례 요지 (선택) | 대법원 종합법률정보 / law.go.kr 판례 — 판시사항·판결요지만 마크다운으로 정리 |
| `sample/` | 동작 확인용 발췌 | 원문과 대조 전 샘플 — 평가 근거로 쓰지 말 것 |

## 규칙
- **법령 버전은 시험일(2026년 1월) 기준 시행본**으로 맞추고 `data/documents.csv` 의 `version`, `collected_at` 을 기입합니다.
  이후 개정본으로 색인하면 시험 당시 정답과 달라질 수 있습니다.
- 법령·판결은 저작권법 제7조의 비보호 저작물이지만, **수험서·해설서·학원 자료는 넣지 않습니다** (이용 조건 + 평가 누수).
- **시험 문제·정답·해설은 색인에 넣지 않습니다.** 시험지는 `data/exam/` 에만 두고 평가 입력으로만 사용합니다.
