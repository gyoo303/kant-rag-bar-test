## 1. 개요 (필수)
- 프로젝트 이름: 민사법 Knowledge Agent (RAG Agent 프로젝트 3)
- 한 줄 설명: 2026년 변호사시험 선택형 민사법 문제를 푸는 사용자가 질문하면, 민사법 법령·판례에서 근거를 검색해 출처와 함께 답하거나 근거가 부족하면 그렇다고 안내하는 RAG 에이전트
- 산출물 형태: 기타 — Python RAG 파이프라인(수집·청킹·색인·하이브리드 검색·re-ranking·답변) + 실행 인터페이스 1개(Streamlit 또는 API) + 평가 실험 기록·비교 보고서
- PM 진행 방식: `분석` (도메인·문서 출처를 사용자가 정함)
- 사이클: `C1` / 상태: `진행 중`
- 기존 결과물: 없음 (이 저장소의 파이프라인 도구·스킬은 제품 결과물이 아니다)
