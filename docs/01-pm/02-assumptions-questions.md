## 2. 가정·모호성

### ASM-001 (확정: Q-001 답 B)  ← REQ-001, REQ-054, C-04
- 내용: "변호사시험 선택형 민사법 문제풀이"에서 사용자가 무엇을 입력하는지 정해지지 않았다. 선택형 문항은 지문 하나에 보기 5개가 붙고 보기마다 다른 법리를 묻는다.
- 위험: 문항을 통째로 넣는 방식이면 한 질문에 근거가 여러 개 필요해 Hit@5(근거 1개라도 상위 5개)와 정답 충족 판정이 어긋난다(REQ-071 다중 근거 누락).
- 질문: Q-001
- 영향 계층: [어플리케이션]

### ASM-002 (확정: Q-002·Q-009 답)  ← REQ-004, C-04, DOC-03 S2
- 내용: "민사법 법령·판례"의 범위(어느 법률, 어느 판례, 몇 건)가 정해지지 않았다.
- 위험: 범위가 넓으면 수집·색인 시간이 5일 일정(프로파일 §4)을 넘고, 좁으면 평가 문항의 근거가 색인에 없어 검색 실패가 아니라 "범위 밖"이 된다.
- 질문: Q-002

## 3. 질문 (1차)

> P2 게이트: 2차까지 답 완료(2026-11-23, user). 미해결 Q 0. Q-010 정답표·문제지 파일은 CR-001로 입력 문서 등록 대기.

### Q-001 사용자는 무엇을 입력하나요?  ← ASM-001
- 선택지:
  - A. **쟁점 질문**: 수험생이 문항의 한 보기에 해당하는 법리를 자연어로 묻는다(예: "점유취득시효 완성 후 등기 전에 소유자가 제3자에게 처분하면 시효취득자는 대항할 수 있나?"). 답은 법리 설명 + 근거 조문·판례.
  - B. **문항 통째**: 지문과 보기 5개를 붙여 넣으면 정답 번호와 보기별 근거를 낸다.
  - C. 둘 다
- 함께 정할 값: (A) 기출 문항의 보기를 쟁점 질문으로 바꿔 평가셋을 만든다.
- 쉬운 설명:
  - A. 무엇이 달라지나: 질문 하나에 법리 하나, 근거 1~2개. / 좋은 점: 발제의 평가 방식(근거가 상위 5개에 있나)과 딱 맞고 구현이 단순하다. / 감수할 점: "문제를 통째로 풀어 주는" 체감은 약하다. / 나중에 바꾸기: 보통 — B를 나중에 A의 반복으로 얹을 수 있다.
  - B. 무엇이 달라지나: 한 번에 보기 5개를 판단해야 해서 근거가 5개 이상 필요하다. / 좋은 점: 실제 문제풀이와 가장 비슷하다. / 감수할 점: 근거가 여러 개라 평가 지표(상위 5개 안에 근거 하나)와 어긋나고, 틀린 보기 하나로 전체가 0점이 된다. / 나중에 바꾸기: 어려움 — 평가셋을 다시 만들어야 한다.
  - C. 무엇이 달라지나: 두 흐름을 모두 만든다. / 좋은 점: 시연이 풍부하다. / 감수할 점: 5일 1인 일정에 비해 크다. / 나중에 바꾸기: 쉬움(빼기는 쉽다).
  - 추천: A — 발제 평가 방식과 맞고 1인 5일 일정 안에 들어간다.
- 답: B. 문항 통째 (2026-11-23)

### Q-002 어느 법령·판례를 검색 문서로 넣을까요?  ← ASM-002
- 선택지:
  - A. **민법 + 관련 판례**: 민법 전 조문과, 평가 문항 쟁점과 관련된 대법원 민사 판례(상한 300건).
  - B. **민사법 3법 + 판례**: 민법·상법·민사소송법 전 조문과 관련 판례(상한 1,000건).
  - C. **민법 일부 편 + 판례**: 민법 중 평가 문항이 다루는 편(예: 물권·채권)만과 관련 판례(상한 200건).
- 함께 정할 값: 판례 건수 상한(A 300 / B 1,000 / C 200, 권장값).
- 쉬운 설명:
  - A. 무엇이 달라지나: 민법 약 1,100개 조문 + 판례 수백 건을 색인한다. / 좋은 점: 변호사시험 민사법 선택형의 대부분이 민법이라 평가 문항을 충분히 덮고, 하루 안에 수집·색인할 수 있는 크기다. / 감수할 점: 상법·민사소송법 문항은 "근거 없음"이 된다(근거 없음 문항으로 쓸 수 있다). / 나중에 바꾸기: 보통 — 법률을 더하면 색인을 다시 만들고 평가셋 근거를 다시 맞춰야 한다.
  - B. 무엇이 달라지나: 시험 범위 전체를 덮는다. / 좋은 점: 범위 밖 질문이 적다. / 감수할 점: 수집·색인·근거 매핑 양이 세 배 가까이 늘고, 비슷한 조문이 많아 검색이 헷갈린다. / 나중에 바꾸기: 보통.
  - C. 무엇이 달라지나: 가장 작은 색인. / 좋은 점: 빠르다. / 감수할 점: 평가 문항을 고를 때 범위에 묶이고 "작은 문서 범위" 한계가 커진다. / 나중에 바꾸기: 쉬움.
  - 추천: A — 시험의 중심 범위를 덮으면서 일정 안에 들어간다.

### Q-007 문항 통째 입력에서 "정답 충족"을 어떻게 채점할까요?  ← ASM-011, REQ-072

- 선택지:
  - A. **정답 번호 + 정답 보기의 근거**: 고른 번호가 공식 정답과 같고, 정답 보기에 대한 설명이 근거와 모순되지 않으면 1.
  - B. **정답 번호 + 보기 5개 모두의 옳고 그름**: 번호가 맞고, 보기 5개 각각의 옳음/틀림 판단과 이유가 모두 맞아야 1.
  - C. **정답 번호만**: 번호가 맞으면 1.
- 쉬운 설명:
  - A. 무엇이 달라지나: 번호와 그 번호를 고른 이유를 본다. / 좋은 점: 우연히 맞힌 경우를 걸러 내면서 채점이 감당할 만하다. / 감수할 점: 다른 보기의 틀린 설명은 점수에 반영되지 않는다(실패 분석에서 따로 본다). / 나중에 바꾸기: 어려움 — 결과 전에 고정한다.
  - B. 무엇이 달라지나: 보기 하나라도 판단이 틀리면 0점. / 좋은 점: 가장 엄격하고 신뢰가 높다. / 감수할 점: 점수가 크게 낮아지고 채점 시간이 5배다. / 나중에 바꾸기: 어려움.
  - C. 무엇이 달라지나: 번호만 본다. / 좋은 점: 채점이 쉽다. / 감수할 점: 근거 없이 찍어도 1점이라 "근거 기반" 평가 취지에 어긋난다. / 나중에 바꾸기: 어려움.

### Q-008 문항 통째 입력에서 "근거 없음" 문항은 무엇인가요?  ← ASM-011, REQ-043, REQ-045, REQ-074
