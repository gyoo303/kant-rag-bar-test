#### 쉬운 설명
- A. 발제 일차표 그대로: 무엇이 달라지나 — 2일차에 4만 건을 다 모으고 색인한 뒤 검색을 만든다. / 좋은 점 — 단순하고 발제 표와 똑같다. / 감수할 점 — 수집이 늦으면 검색 개발이 하루 통째로 밀린다. / 나중에 바꾸기: 쉬움 — 일정만 바꾸면 된다.
- B. 작은 색인으로 먼저 시작: 무엇이 달라지나 — 2일차에 조문 + 판례 1만 건으로 검색을 먼저 만들고, 나머지 판례는 그동안 이어서 모은다. / 좋은 점 — 수집이 늦어도 개발이 멈추지 않는다. / 감수할 점 — 색인이 커진 뒤 개발용 결과를 한 번 더 확인해야 한다. / 나중에 바꾸기: 쉬움.
- 추천: B — 4만 건을 모으는 데 얼마나 걸릴지 아직 모르기 때문이다.
