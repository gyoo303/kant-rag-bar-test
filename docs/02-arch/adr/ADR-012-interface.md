# ADR-012: 실행 인터페이스 (화면 기술)
- 상태: Accepted (user, 2026-11-23) — 추천안
- 관련 계층: [어플리케이션]
- 근거: C-10, AQ-002, TR-09, US-11, SCR-01, ASM-008, REQ-021, REQ-022

## 맥락
발제는 Streamlit 또는 웹 화면/API 중 하나면 되고 UI 완성도는 평가하지 않는다(C-10). 사용자는 1명, 로컬 실행이다(ASM-008). 평가 일괄 실행은 화면이 아니라 명령줄로 한다(US-13).

## 검토한 옵션
| 옵션 | 장점 | 단점 | AI 부채 영향 | 외부 기준 영향 | 되돌리기 비용 |
|---|---|---|---|---|---|
| A. Streamlit 화면 1개 (`answering` 응용 서비스를 직접 호출) | 파이썬 파일 하나, 표·접힘 영역 기본 제공, 서버 계층 불필요 | 다른 프로그램이 호출할 API는 없음 | 낮음 | CRT-06 화면 증빙 충분 | 낮음 |
| B. FastAPI API + API 문서 화면 | 다른 프로그램이 호출 가능, 응답 코드 체계 | 요청·응답 스키마·응답 코드 대응을 추가로 설계·시험, 화면은 API 문서뿐 | 중(범위 대비 과함) | 중립 | 중 |

## 계층 관점 설명
- A: `src/lawqa/entrypoints/streamlit_app.py` → `AnswerService.answer(item, config)` → `Answer` 표시. 화면은 `Answer`만 읽고 도메인 규칙을 다시 구현하지 않는다.
- 명령줄 진입점(`python -m lawqa ...`)은 인터페이스와 별개로 둔다(수집·색인·평가).

## 결정
결정: A — 1인 로컬 사용에 가장 단순하고, 화면 상태 6종(SCR-01)을 바로 보여 줄 수 있다.

## 결과
- 좋아지는 점: FE 티켓 1~2개로 끝남
- 감수할 점: 외부 호출용 API 없음(필요하면 선택 등급 M6에서)
- 후속 작업: A4 PAGE-01, TKT-FE

## 쉬운 설명
- A. Streamlit 화면: 무엇이 달라지나 — 파이썬 파일 하나로 입력칸·결과 표가 있는 화면을 띄운다. / 좋은 점 — 가장 빨리 만들고 보기 쉽다. / 감수할 점 — 다른 프로그램이 부를 수 있는 API는 없다. / 나중에 바꾸기: 쉬움(답변 기능이 분리되어 있어 API를 나중에 붙일 수 있다).
- B. API 서버: 무엇이 달라지나 — 요청을 받아 JSON으로 답하는 서버를 만든다. / 좋은 점 — 다른 프로그램과 연결할 수 있다. / 감수할 점 — 요청 형식·응답 코드까지 설계·시험해야 하고, 화면은 API 문서뿐이다. / 나중에 바꾸기: 보통.
- 추천: A — 발제가 UI 완성도를 평가하지 않고 사용자도 1명이다.
