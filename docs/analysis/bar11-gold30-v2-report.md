## 1. 측정 기준

| 항목 | 기준 |
|---|---|
| 정답 근거 일치 | 판례는 **사건번호**, 조문은 **'법령명 제N조'** 단위. 같은 판결의 다른 항목·조각, 같은 조문의 다른 항도 일치로 본다 |
| 검색 | 지문마다 그 지문 질의로 검색한 결과 목록(v2: 상위 5개)과 정답 근거 비교 |
| 판단 입력(Context) | 문항의 모든 지문 검색 결과를 합친 근거 묶음 (v2: 지문당 상위 4개, 문항당 평균 16.5개 청크) |
| 지문 분류 | **A** 정답 + 정답 근거 인용 · **B** 정답이지만 정답 근거 미인용 · **C** 정답 근거가 입력에 있었는데 틀림 · **D** 정답 근거가 입력에 없고 틀림 · **E** 유보 |

정답 근거는 한 에이전트의 색인에서 모델이 고르고 규칙으로 거른 것이다(사람 전수 검토 아님). **같은 법리를 말하는 다른 판례**를 찾으면 이 기준에서는 불일치로 센다 — 그래서 B·근거 밖 정답은 실제보다 많게 나올 수 있다 (4-② 참고).

## 3. 사실 — 적합한 문서가 맥락으로 쓰였나

**오답 문 24 (○×형)**: 지문 ㄱ(검색 누락)·ㄷ(근거는 있으나 '추정' 표현 미확인)을 유보 → 보기 ②·⑤가 0.25 동점 → 앞 번호 ② 선택. 틀린 판단은 없었고 유보 두 개가 보기를 가르지 못한 것이 원인이다. v2 는 동점 재판단이 꺼져 있어 상태도 `tie` 가 아닌 `ok` 로 기록됐다.

- 맞힌 29문항 중 19문항은 **지문 일부를 정답 근거 없이 넘겼다** (유보하거나 다른 문서로 판단). 선택형은 지문 하나 정도 유보해도 나머지로 답이 정해지는 경우가 많아서, 문항 정답률(96.7%)이 근거 품질(완전 근거 33.3%)보다 훨씬 높게 나온다.
- 틀린 판단(C·D)은 1개뿐이다. **v2 의 실점 구조는 "틀린 판단"이 아니라 "유보로 정보가 사라짐"** 이다.

### 4-② 추가 추론(생성형 모델 판단 개입)이 발생했는가

| 신호 | 값 | 해석 |

- 모델 단독 실력과의 교차(RAG만 맞음 / closed-book만 맞음)는 closed-book 실행이 없어 이번에 계산하지 않았다.
