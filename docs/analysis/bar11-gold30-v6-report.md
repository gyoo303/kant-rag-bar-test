## 1. 측정 기준

v2 리포트와 같다. 판례는 **사건번호**, 조문은 **'법령명 제N조'** 단위로 정답 근거와 맞추고, 지문을 A~E 로 나눈다 (**A** 정답 + 정답 근거 인용 · **B** 정답, 정답 근거 미인용 · **C** 입력에 근거 있는데 틀림 · **D** 근거 없이 틀림 · **E** 유보).

v6 는 지문당 검색 결과를 8개(final_k 8)까지 남기고 그중 5개를 판단 입력에 넣는다. Recall@k 는 v2 와 같은 k 로 비교했다. 판단 입력이 문항당 **16.5개 → 38.9개 청크**로 늘었다 (지문당 5개 + 연결 근거 + 같은 판결 항목 + 준용 조문).
