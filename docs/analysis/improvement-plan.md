## 관찰
- RAG: 근거 있으면 정확(확신 오답 진술 10), 근거 없으면 유보(53 진술, 32/70 문항)
- closed-book: RAG 유보 진술 53개 중 41개를 맞힘, 그러나 단독으로는 확신 오답 57개(평균 0.90)
- 두 방식의 강점이 반대 → 근거 판단 우선, 빈칸만 지식으로 약하게 보완

## 파이프라인
```
문항 → 진술 분리
  → [A 검색 보완] 진술 중심 질의·예외 탐색 → 근거 5개 + 같은 판결 다른 항목 + 준용 조문
  → [B 판단 보완] 근거로 진술별 판단 (사실관계·전 항목·예외 우선 규칙)
  → 유보 진술이 있으면 [C 판단 결합] 같은 모델 closed-book 판단 → 유보 진술만 확신도×0.5 로 채움
  → 정답 번호 계산 → 진술별 "근거 판단 / 지식 판단" 표시
```
