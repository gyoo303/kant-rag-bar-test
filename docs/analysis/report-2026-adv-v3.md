## 5. 결론

- 적대적 변형(바꿔 말하기·숫자·이중부정·무관한 사례 덧붙이기)에도 v3 는 94% 를 유지했고, 변형된 진술에서 오히려 덜 틀렸다. 근거를 찾아 원문과 대조하는 방식이 표현 변화에 강하다는 뜻이다.
- 약점은 **문장 해석**(이중부정, 조문 단서의 범위)과 **점수 계산의 동점**이다. 검색이 아니라 판단·계산 단계의 문제라 프롬프트와 계산 규칙으로 다룰 수 있다.
- 1·2·5·6 은 v4 에 아직 없다. 구현하면 프리셋 `d` 에 넣고, 효과는 원본 튜닝 세트(53문항)로 확인한다. 변형본은 test 문항이 섞여 있어 설정을 고르는 데 쓰지 않는다.
