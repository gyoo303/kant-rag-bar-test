# 2026 변호사시험 민사법 선택형 70문항 — RAG 풀이 결과 및 오답 분석

> 작성 2026-11-24 · 브랜치 `sanghyuk` · 상세 원자료: `results/`, `docs/analysis/all70-v1.md`, `docs/analysis/all70-v2.md`

## 1. 요약

- **v2(버그 수정판) 58/70 정답(82.9%), 오류 0건.** v1 은 53/70 이었으나 오류 5건이 모두 응답 파싱 버그였고, 수정한 파서로 다시 읽으면 5건 모두 정답 → 실질 성능은 두 실행이 같음.
- 오답 12문항은 v1·v2 가 **완전히 동일**. 정답 번호 계산 규칙에서 틀린 문항은 **0건** — 모든 오답은 검색 또는 진술 판단 단계에서 발생.
- 주요 원인: ① 사례형 지문이 검색 질의를 지배해 진술별 근거를 못 찾음 ② 근거 부족 시 판단 유보(unknown) ③ **일반 원칙만 검색되고 예외·특칙을 놓쳐 확신을 갖고 틀림** ④ 판례·규칙 미수집.
- 판단 오류 6건 모두 **결정적 근거가 색인에 있었음** → 검색·근거 구성·프롬프트 개선 여지가 큼.

> ⚠ 이 두 실행은 70문항 전체를 푼 **탐색 실행**이며 최종 평가용 test 17문항이 포함되어 있다. 이 결과로 test 에 맞춰 튜닝하지 않으며, 개선안의 효과는 dev·extra 로만 검증하고 최종 수치는 고정된 `eval/test.json` 으로 별도 산출한다.

1. 검색이 진술과 어휘가 겹치는 **일반 원칙**을 상위에 올리고 **예외·특칙**을 놓친다. 시험 함정은 주로 예외를 묻는다.
2. 판결요지를 항목 단위로 청킹해 같은 판결의 전제와 결론이 분리된다.
3. 사실관계가 다른 판례를 단어 유사성만으로 유추한다.
4. 진술 문구와 맞는 부분만 읽는다.
5. 틀린 판단의 확신도가 0.76~1.0 으로 높다. unknown 보다 위험한 유형이다.

### 4.6 실행 간 변동

같은 설정인데 진술 단위 판단이 달라졌다: 문 28 의 유보 진술이 ㄱ(v1) → ㄷ(v2), 문 13ㄴ 이 unknown(v1) → true 0.85 오답(v2). 정답 수는 같았지만, 최종 test 결과는 **2~3회 반복 실행의 평균과 범위**로 보고하는 것이 안전하다.

## 6. 한계와 다음 단계

- closed-book(검색 없는 기준선) v2 결과가 아직 없어 RAG 효과를 수치로 비교하지 못했다. v1 closed-book 은 15문항에서 중단됐고 그중 6건이 오류라, 양쪽이 모두 풀린 9문항(RAG 8 · closed-book 5)만 참고로 남긴다.
- 70문항 전체 실행이라 test 문항이 포함된 탐색 결과다. 최종 평가는 test 고정(`frozen: true`) 후 `eval/test.json` 으로 A/B/C·C+리라이트·closed-book 을 실행한다.
- 정답 판단에 쓴 근거는 수집한 법령 13개와 대법원 민사·가사 판례 범위에 한정된다.
- 다음 단계: closed-book v2 → 개선안 1~4 구현 → dev·extra 비교 → test 고정·최종 실행(반복 2~3회) → 사람 채점(근거 적합) → `report.md` 반영.
