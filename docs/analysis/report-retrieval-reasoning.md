## 0. 측정 방법

- **정답 근거표(gold)** 가 있는 것은 2026 test 17문항뿐이다. 여기서만 "정확한 문서를 찾았는가"를 직접 잰다.
- 나머지는 대리 지표를 쓴다. 진술마다 루나가 **인용한 근거(cited_chunk_ids)** 가 실제 문맥에 있었고 그 판단이 맞으면 "검색된 근거로 맞힘"(E+)으로 본다. v5 는 인용 문장이 근거 원문에 그대로 있는지도 확인한다.
- 진술 판단 분류
  - **E+** 근거를 인용해 맞힘 · **E−** 근거를 인용했는데 틀림 (근거는 찾았으나 판단 오류)
  - **U** 근거 부족으로 유보 · **K±** 근거 없이 모델 지식으로 채움 (지식 결합)
- 검색 단계별 순위는 기록의 `vector_rank`(벡터 상위 20 안 순위), `bm25_rank`, `pre_rerank_rank`(RRF 순위), `rerank_rank` 를 쓴다.
- bar12 의 진술 정답은 레드팀 정답표 기준이다(문 13 정답표 모호, 개수형 2·21 정답표 의심은 진술 집계에서 빠짐).

**해석**

- **벡터만 썼다면** 결정적 근거의 약 **4분의 1이 상위 5 밖**(최종 문맥에 못 들어감)이고, 3~9% 는 상위 20 에도 없었다. 벡터 단독 품질은 "대체로 근처까지는 찾지만 정확한 1~5위로는 부족"한 수준이다.
- 벡터가 놓친 근거는 대부분 **BM25 가 찾았다**(조문 번호·사건번호·"3분의 2" 같은 정확한 표현). 반대로 BM25 가 놓친 것은 벡터가 찾았다(바꿔 말한 표현). 두 검색기를 RRF 로 합친 것이 핵심이다.
- **리랭커**가 RRF 6위 이하에 있던 근거의 10~17% 를 최종 5위 안으로 끌어올렸다. 리랭커가 없었다면 그만큼 문맥에서 빠졌다.
- 판단에 쓰인 근거의 60% 안팎은 **최종 1위**였다(예: bar12 222/367). 진술별로 검색하고 리랭커로 다시 줄 세운 결과, 정답 근거가 대부분 맨 위에 온다.

## 2. 검색 결과를 활용한 추론

### 2.1 근거를 찾았는데 틀린 경우 (E−) — 진술 8~11개/실행

검색 실패가 아니라 **받은 근거를 잘못 적용**한 경우다. 원칙 판례만 보고 예외를 놓침(2026 문 13), 같은 판결의 결론 항목 누락(2026 문 9 — v3 의 같은 판결 항목 확장으로 해결), 조문 단서의 적용 대상 오독(변형 문 55), 이중부정 오독(변형 문 47), 사실관계가 다른 조문 적용(2026 문 61). 이 오류들이 v4·v5 판단 프롬프트 보강의 근거가 됐다.

### 2.2 검색 품질이 낮았을 때 — 추론이 어떻게, 얼마나 일어났나

| 경로 | 동작 | 실행별 규모 | 효과 |
|---|---|---|---|
| **① 번호 계산이 오류를 흡수** | 유보·틀린 진술이 있어도 나머지 진술로 보기가 하나로 정해짐 | 정답 문항 중 v2 **27**, v3 6, 변형 v3 11, bar13 7, bar12 9 | 가장 큰 안전장치. v2 는 유보 53개를 대부분 여기서 흡수 |
| **② 판단 프롬프트 v2 의 "핵심 법리가 있으면 판단"** | 근거가 일부만 맞아도 유보하지 않고 판단 | 유보 진술 v2 53 → v3 **0** | 유보를 없앴지만 일부는 확신 오답으로 바뀜 (튜닝 세트 확신 오답 4 → 8) |
| **③ 지식 결합** (v3 의 c 구성) | 그래도 유보한 진술만 모델 지식으로 채움 (확신도 ×0.5) | 채운 진술 v3 13 (10 정답), 변형 v3 16 (12 정답), bar13 13 (12 정답) | 문항을 바꾼 경우: 튜닝 +1·−1, 변형 +2(35·43), bar13 +1(53). 지식 판단 정확도 75~92% |
| **④ 근거 확장** (같은 판결 다른 항목, 준용 조문, 긴 조문 조각) | 검색된 근거와 연결된 근거를 덧붙임 | 확장 근거를 인용해 맞힌 진술 v3 7, 변형 v3 5, bar13 8, bar12 2 | 2026 문 9(같은 판결 [2]), 문 53(준용 제186·190조)을 살림 |
| **⑤ 재판단·예비 규칙** (v4·v5) | 동점·근소 차이면 갈리는 진술만 다시 판단 | bar12 재판단 10문항 | 문 39 를 재판단으로 맞힘, 문 69 는 동점 유지 |

**정리**: 검색이 부족할 때 에이전트는 "모르겠다"로 멈추지 않고 ①→②→③ 순서로 메운다. ① 은 비용 없이 강력하고, ② 는 유보를 줄이는 대신 확신 오답 위험을 키우며, ③ 은 맞을 확률이 75~92% 인 기억 판단이다. 검색이 실패하고 ①~③ 도 통하지 않은 경우가 남은 오답의 대부분이다(bar13 38·65, bar12 40).

### 3.3 결론

1. **검색 품질**: 하이브리드 + 리랭커 + 진술별 검색으로, 색인에 근거가 있는 경우 정확한 문서를 거의 찾는다(gold 17/17, 판단 근거의 96% 가 상위 20 안). **벡터 단독은 부족하다** — 결정적 근거의 약 4분의 1을 상위 5 밖에 둔다.
2. **추론**: 검색이 부족할 때 번호 계산 흡수 → 판단 규칙 → 지식 결합 순으로 메운다. 흡수는 강력하고 비용이 없지만, 판단 규칙과 지식 결합은 확신 오답을 늘릴 수 있다.
3. **남은 실패의 대부분은 검색 단계다**: 색인에 없음(4건), 리라이트가 쟁점을 비켜 감(2건), 역방향 준용 미추적(1건), 실행 간 검색 변동(1건). 판단 단계 실패(E−)는 실행당 진술 8~11개로 줄었다.
