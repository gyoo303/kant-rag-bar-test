# KANT COURT 법정 모드

KANT COURT는 민사법 질문과 변호사시험 선택형 문항을 기존 KANTNYANGI RAG로 검토하는 법률 학습용 웹 모드입니다. 일반 모드에서는 채팅, 검색 과정 비교, 시험지 전체 풀이를 이용할 수 있습니다. 법정 모드에서는 같은 엔진에 사건을 접수하고, 검색 근거와 판단 결과를 재판 장면으로 확인합니다.

## 실행

저장소 루트에서 다음을 실행합니다.

    uv sync
    uv run kant-rag-web

첫 실행 전 .env.example을 .env로 복사해 사용하는 LLM 공급자의 설정과 API 키를 입력합니다. 기본 설정은 OpenAI이며 OPENAI_API_KEY가 필요합니다. .env는 로컬에 보관합니다. 이미 준비된 색인이 있으면 저장소 루트의 index/에 두고, 원문을 준비한 상태에서 직접 생성하려면 uv run kant-rag build-index를 실행합니다. 원문 준비와 모델 설정은 [README 빠른 시작](../README.md)과 [일반 웹 모드 안내](web-ui.md)를 참고하세요.

브라우저에서 http://127.0.0.1:8600을 열고 상단의 **법정 모드**를 선택합니다. http://127.0.0.1:8600/court로 직접 열 수도 있습니다. **사건 접수 → 무권대리 예제 사건 → 심리 시작**으로 바로 시연할 수 있습니다.

## 기능과 데이터 흐름

- 첫 입장에서는 문 개방, 법정 타이틀, 재판장 안내가 이어집니다. 건너뛰기, 같은 탭에서의 재입장 생략, 설정의 다시 보기를 지원합니다.
- 심리 대기 중에는 실제 경과 시간을 표시합니다. 응답이 반환되면 조사관·분석관·검증관·재판장 장면을 재생합니다. 사건 하나당 기존 POST /api/chat 요청 한 번을 사용합니다.
- 증거 원문을 열람하고 근거 문장을 제출할 수 있습니다. 선택형 한 문항에서는 선고 전에 내 판단을 선택하고 판결문에서 재판부 판단과 비교할 수 있습니다.
- 판결문은 실제 응답에 포함된 선택 번호, 지문별 판단과 이유, 인용 근거를 표시합니다. 근거 부족은 판정 보류로, 연결 오류와 시간 초과는 심리 중단으로 안내합니다.
- 기존 FastAPI 서버는 /court와 정적 파일을 제공하고, 검색·생성·문항 판정·평가에는 기존 코드를 사용합니다.

## 에셋과 제한 사항

- 화면에서 사용하는 캐릭터, 법정, 문과 의사봉 이미지는 최적화한 WebP입니다. [에셋 출처](../app/web/court/assets/SOURCES.md)에 제공 이미지와 브라우저 합성 효과음의 출처를 기록했습니다.
- 사운드는 기본 음소거이며 사용자 동작으로 활성화합니다. 볼륨과 연출 속도, 동작 줄이기, 건너뛰기를 지원합니다.
- 법정 모드는 네트워크와 LLM 응답 및 준비된 색인에 의존합니다. 첫 요청에는 색인과 모델 초기화 시간이 더 걸릴 수 있습니다. 판정은 학습용으로 확인된 근거 범위를 따릅니다.
- 직전 사건의 기록은 현재 브라우저 탭의 세션에 보관합니다. 법정 대화는 일반 채팅 기록과 별도로 표시됩니다.
- 캐릭터 장면은 완성 일러스트를 사용하는 컷 연출입니다. 세로 화면의 의사봉 컷은 이미지 속 글자를 살리기 위해 여백을 유지합니다.

## 검증

Python 회귀 테스트는 uv run pytest -q로 실행합니다. 브라우저 테스트는 웹 서버를 실행한 뒤 Node.js와 Playwright가 준비된 환경에서 node --test tests/court_interaction.cjs로 실행합니다. 환경 변수 KANT_COURT_BASE_URL은 서버 주소, PLAYWRIGHT_MODULE과 COURT_BROWSER_EXECUTABLE은 필요한 경우 보유 중인 Playwright 및 Chromium 계열 브라우저를 지정합니다. 브라우저 테스트는 응답을 모의 처리해 API 키 없이 실행할 수 있습니다.
