# 문서 목록·데이터 이용 조건

## 출처
| 항목 | 내용 |
|---|---|
| 제공 | 법제처 국가법령정보 공동활용 OPEN API (https://open.law.go.kr) |
| 사용 API | 판례 목록 `lawSearch.do?target=prec`, 판례 본문 `lawService.do?target=prec`, 법령 `target=law` |
| 인증 | 개인별 OC (각자 신청, 서버 IP 등록). 저장소에 넣지 않음 |
| 이용 조건 | 법제처 제공 법령정보: 출처 표기 필수 ("법제처 국가법령정보센터"), 위·변조 금지. 짧은 시간 과도한 호출 시 이용 제한 가능 |
| 외부 모델 전송 | 공개 판례(당사자 비실명 처리됨) → OpenAI 임베딩·생성 API 전송 가능 (팀 확인) |

## 문서 ID 규칙
- 판례: `doc_id` = 판례일련번호 (예: 625343), 표시용 `case_no` = 사건번호 (예: 2025다212572)
- 판례 필드(원문 위치): 판시사항 · 판결요지 · 참조조문 · 참조판례 · 판례내용
- 청크 ID: `{doc_id}:{section}:{순번}` (예: `625343:판결요지:0`) — 확정 시 여기 갱신
- 조문: `doc_id` = `law:{법령명}:{조번호}` (예: `law:민법:750`)
