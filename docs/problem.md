# 문제 정의 (STEP 1) — 초안

> 팀 합의 전 초안입니다. **결과를 보기 전에** 목표값·채점 기준을 확정하고, 이후 변경은 아래 변경 기록에 남깁니다.

## 0. 프로젝트 주제
**AI 가 틀리도록 낸 문제를 푸는 AI** — 2026년 제15회 변호사시험 민사법 선택형 70문항을
'AI 함정 문항'으로 보고, 조문·판례 검색 근거로 그 함정을 피해 정답을 맞히는 RAG 에이전트를 만든다.
(팀 가설: 출제가 AI 의 약점 — 미세한 숫자·예외 변경, 최신·변경 판례, 다단계 사례 적용, 부정 극성 — 을 노린다.
이 가설 자체는 closed-book 기준선과의 비교로 검증한다.)

## 1. 사용자와 업무
- **사용자:** 변호사시험 수험생, 그리고 수험생 질문에 답하는 학습 조교·튜터
- **문제:** 범용 AI 에게 시험 문제를 물으면 그럴듯한 근거와 함께 틀린 답을 내는 경우가 많고, 수험생은 어느 보기에서 왜 틀렸는지 확인하기 어렵다
- **기존 탐색 과정:** 보기마다 법령집·판례집·수험서를 찾아 대조 → 한 문항에 여러 법령(민법·민사소송법·상법·특별법)과 판례가 섞여 있어 시간이 오래 걸리고, 개정 전 조문을 보는 실수가 잦음
- **질문 범위:** 민법(총칙·물권·채권·친족상속), 민사소송법, 상법, 민사집행법 및 주요 민사 특별법

## 2. AI 함정 유형과 오답의 영향
| 함정 유형 | 범용 AI 가 틀리는 이유 | RAG 의 대응 |
| --- | --- | --- |
| 숫자·기간 | 기억 속 숫자를 확신 있게 말함 | 조문 원문 대조 |
| 최신 판례 / 판례 변경 | 학습 시점 이후·이전 법리 혼재 | 2011~2025 판결요지 검색, 시험일 기준 법령 버전 |
| 유사 제도 혼동, 주체 바꿔치기 | 비슷한 문장 패턴을 같은 것으로 봄 | 진술별 근거 대조 |
| 예외·단서 | "특별한 사정이 없는 한" 등 조건 누락 | 판결요지 원문의 조건 확인 |
| 사례 적용 | 사실관계 → 법리 적용의 다단계 추론 실패 | 쿼리 리라이트로 쟁점 추출 후 검색 |
| 부정 극성, 전 진술 판단 | '옳지 않은 것' 극성 착오, 진술 하나 오판으로 전체 오답 | 진술별 판단 후 규칙으로 정답 결정 |

- 태그: `mcq/traps.py` (자동 6종 + 팀 수동 4종), 결과는 `summary.json` 의 `accuracy_by_trap`
- 틀린 정오 판단을 **그럴듯한 근거와 함께** 제시하면 학습자가 잘못된 법리를 외우게 됨 → 무근거 단정이 가장 큰 위험
- 근거가 없을 때는 정답 번호를 지어내지 말고 "판단 근거 부족" 을 안내

## 3. RAG 를 선택한 이유와 검증 방법
- 함정의 대부분은 **특정 조문·판례의 요건/효과/기간/예외**를 원문으로 확인하면 풀린다 → 검색 근거 대조가 핵심
- 근거 청크(조문·판결요지 ID)를 함께 제시해 학습자가 원문을 직접 확인할 수 있음
- **검증:** 같은 모델·같은 진술 판단 방식으로 ① 검색 없는 closed-book 기준선, ② A/B/C, ③ C+리라이트를 비교하고 함정 유형별 정답률 차이를 본다

## 4. 제외 범위
- 사례형·기록형(서술형) 답안 작성, 모델 학습·파인튜닝
- 수험서·해설서·학원 자료 색인 (이용 조건 + 평가 누수)
- 실제 법률 자문

## 5. 성공 기준 (사전 확정 필요)
| 우선순위 | 항목 | 목표값(팀 결정) | 측정 |
| --- | --- | --- | --- |
| 1 | 정답률 (선택형 17문항, 자동) | | `eval` summary `accuracy` |
| 1 | closed-book 대비 정답률 향상 (함정 유형별) | | `--modes closed_book` 별도 실행, `accuracy_by_trap` |
| 1 | Hit@5 (허용 근거가 진술별 top-5 에 포함) | | 근거 표기 문항 기준 |
| 1 | 근거 적합 (인용 조문이 판단을 뒷받침) | | 사람 채점 + 교차 검토 |
| 1 | 근거 없음 3문항 정보 부족 안내 | 3/3 | 사람 채점 |

- 기준 비교: 같은 모델의 **검색 없는 풀이(closed-book)** 를 기준선으로 측정 (본 60건과 별도 보고)
- 개선 전 수험생 풀이 시간은 측정하지 않았으므로 시간 절감률은 주장하지 않음

## 6. 알려진 위험
- **판례 의존 보기**: 법령만 색인하면 판례 법리를 묻는 보기는 검색 근거가 없음 → 판례 요지 수집 범위가 성능을 좌우
- 사례형 지문(긴 발문)은 진술별 검색 질의가 흐려질 수 있음 → `mcq.stem_chars_in_query` 를 개발셋으로 조정
- 조합형·개수형은 진술 하나만 틀려도 오답 → 진술별 정확도를 따로 기록해 원인 분리
