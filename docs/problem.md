# 문제 정의 (초안 — 팀 회의에서 확정)

> 결과를 보기 **전에** 확정하고, 이후 변경은 아래 「변경 기록」에 남긴다.

## 1. 사용자
- 변호사시험 민사법 수험생 / 법률사무소 신입 변호사 (팀 확정 필요)

## 2. 기존 탐색 과정과 어려움
- 쟁점에 맞는 대법원 판례를 찾으려면 키워드 검색 → 판례 여러 건 열람 → 판시사항·판결요지 대조가 필요
- 무효/취소, 해제/해지, 착오/사기처럼 **유사 법리·예외 조건**을 혼동하기 쉬움
- (측정하지 않았다면 소요시간 절감률을 성과로 주장하지 않음)

## 3. 오답·근거 부족의 영향
- 잘못된 판례·법리를 근거로 학습하거나 답안·의견서에 인용할 위험
- 근거 없이 단정하는 답변은 사용자가 검증하기 어려움 → **출처 제시와 정보 부족 안내가 필수**

## 4. RAG를 쓰는 이유
- 판례·조문은 원문 근거 확인이 핵심 → 검색된 원문을 근거로 답하고 사건번호로 추적 가능
- LLM 단독 답변 대비 개선 여부를 **LLM 단독 기준선**과 비교해 확인

## 5. 질문 범위 / 제외 범위
- 포함: 민법 (팀 확정: 전체 or 주제 — 예: 임대차·소멸시효·채권양도), 관련 대법원 민사 판례
- 제외: 형사·행정·세무 판례, 실제 법률 자문, 외부 시스템 쓰기, 모델 학습·파인튜닝
